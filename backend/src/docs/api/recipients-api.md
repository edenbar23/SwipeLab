# Recipients API Endpoints

Base path: `/api/v1/dashboard/recipients`

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Get all recipient groups |
| `POST` | `/` | Create a new recipient group |
| `PUT` | `/{groupId}` | Update an existing recipient group (add/remove users) |
| `DELETE` | `/{groupId}` | Delete a recipient group |
