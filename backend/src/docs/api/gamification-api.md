# Gamification API Endpoints

Base path: `/api/v1/gamification`

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/user-info` | Get personal gamification stats (points, rank) |
| `GET` | `/leaderboard` | Get the global leaderboard |
| `GET` | `/rank` | Get rank details for the current user |
| `GET` | `/challenges` | List available and active challenges |
| `GET` | `/me/badges` | Get badges earned by the current user |
